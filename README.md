# Погода OpenWeather: CLI и GUI

Учебное Python-приложение для получения текущей погоды через OpenWeather. При запуске можно выбрать консольный (CLI) или графический (GUI) интерфейс. Оба варианта используют общую логику запросов, кэширования, повторных попыток и обработки ошибок.

## Возможности

- поиск города через OpenWeather Geocoding API;
- текущая погода по координатам через Current Weather API;
- вывод температуры в градусах Цельсия и описания на русском языке;
- консольные режимы «по городу» и «по координатам»;
- графическое окно на Tkinter с теми же режимами;
- единое поле координат в GUI и вставка значений из буфера обмена одной кнопкой;
- API-ключ хранится в `.env`, который исключён из Git;
- до трёх повторных попыток при `429`, временных ошибках сервера и сетевых сбоях;
- кэш последнего успешного ответа в `weather_cache.json` с предложением использовать его при сетевой ошибке, если кэшу меньше трёх часов;
- понятные сообщения об ошибках без вывода трейсбеков;
- тесты общей логики на стандартном `unittest` с моками.

## Требования

- Python 3.10 или новее;
- пакеты `requests` и `python-dotenv` из `requirements.txt`;
- Tkinter для GUI. В используемом Python 3.14.2 доступен Tk 8.6; отдельная установка не потребовалась.

Проект проверялся на macOS Monterey 12.7.6 (Intel) с Python 3.14.2.

## Установка

Из корневой папки проекта:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

Без активации окружения:

```bash
.venv/bin/python -m pip install -r requirements.txt
```

## API-ключ

Получите ключ в личном кабинете OpenWeather: <https://home.openweathermap.org/api_keys>.

Запишите его в локальный файл `.env`:

```dotenv
API_KEY=ваш_ключ_OpenWeather
```

Файл `.env` находится в корне проекта. Добавьте ключ в него и не передавайте этот файл в Git. Шаблон без секрета находится в `.env.example`. Файл `.env` добавлен в `.gitignore` и не должен попадать в репозиторий.

Новый ключ OpenWeather может активироваться не сразу. Если API возвращает `HTTP 401`, подождите несколько минут, проверьте ключ в личном кабинете и перезапустите приложение.

Без ключа CLI выводит подсказку и завершает работу, а GUI показывает сообщение и блокирует запросы.

Выбор интерфейса:

Если виртуальное окружение не активировано, используйте `.venv/bin/python` вместо `python`.

## CLI

После выбора CLI появляется меню:

```text
Режим ввода:
1 — по городу
2 — по координатам
0 — выход
```

### По городу

Введите название города. Пример:

```text
Введите название города: Москва
Погода в Москва: 12.4°C, пасмурно
```

Название в строке результата берётся из введённого значения.

### По координатам

Введите широту и долготу через пробел, запятую или точку с запятой. Поддерживаются десятичная точка и запятая, а также знак градуса:

```text
Введите широту и долготу (например, 55.75 37.62 или 43,585°, 39,723°): 43,585°, 39,723°
```

Допустимые форматы: `55.75 37.62`, `55,75 37,62`, `55.75, 37.62`, `43,585°, 39,723°`, `43.585° 39.723°`. Широта должна быть от `-90` до `90`, долгота — от `-180` до `180`. Название города для результата берётся из ответа OpenWeather; если его нет, используются координаты.

В режиме координат можно ввести `v` или `в`, чтобы вставить строку из буфера обмена целиком, например `43,585°, 39,723°`. Ввод `0` возвращает в меню. Обычная вставка `Cmd+V` в терминале также работает.

## GUI

В окне доступны переключатель «По городу» / «По координатам», поля ввода и кнопка «Узнать погоду». В режиме координат используется одно поле, как в CLI. Кнопка «Вставить из буфера» вставляет текст целиком, например `43,585°, 39,723°`, и сразу проверяет формат. Результат выводится в той же строке формата, что и в CLI.

Сетевой запрос выполняется в фоновом потоке, поэтому окно не зависает во время запросов и пауз между повторными попытками. Кнопка блокируется до завершения операции. После успешного запроса рядом со статусом «Данные получены» отображаются дата и время получения в местном часовом поясе (без секунд). При временной сетевой ошибке GUI предлагает вывести свежие данные из кэша через диалог подтверждения.

## Кэширование

После каждого успешного запроса создаётся `weather_cache.json`:

```json
{
  "city": "Москва",
  "lat": 55.75,
  "lon": 37.62,
  "fetched_at": "2026-10-24T18:18:42+00:00",
  "weather": {
    "name": "Москва",
    "main": {
      "temp": 12.4
    },
    "weather": [
      {
        "description": "пасмурно"
      }
    ]
  }
}
```

Фактический ответ OpenWeather сохраняется полностью в поле `weather`. Время `fetched_at` записывается в UTC и отображается пользователю в локальном часовом поясе.

Правила использования кэша:

- при временной сетевой ошибке приложение предлагает вывести последний успешный ответ;
- кэш используется только если с момента сохранения прошло меньше трёх часов;
- перед выводом показывается город и время сохранения данных;
- ошибки неверного API-ключа и ненайденного города не подменяются данными кэша;
- отсутствующий или повреждённый `weather_cache.json` игнорируется;
- `weather_cache.json` исключён из Git, поскольку содержит историю местоположения.

## Повторы и обработка ошибок

Запросы выполняются с тайм-аутом 10 секунд. При HTTP `429`, ответах `500`, `502`, `503`, `504` и сетевых исключениях выполняются до трёх повторов с паузами 1, 2 и 4 секунды: всего до четырёх попыток.

Постоянные ошибки не повторяются. Для них выводятся отдельные сообщения:

- отсутствующий `API_KEY`;
- неверный ключ (`HTTP 401`);
- пустой ответ геокодинга;
- город не найден;
- некорректные координаты;
- ошибка HTTP с текстом от OpenWeather;
- некорректный JSON;
- недоступная сеть после исчерпания повторов.

## Известные ограничения

- Для реальной работы нужен действующий ключ OpenWeather. Без ключа оба интерфейса показывают подсказку и не выполняют запросы.
- Название города в режиме координат может быть на английском: OpenWeather не локализует поле `name`, хотя описание погоды запрашивается с `lang=ru`.
- Кэш хранит только последний успешный ответ. При запросе другого города интерфейс явно показывает, для какого города взяты данные.
- GUI требует доступный Tkinter и графическую сессию. Если Tkinter недоступен, CLI можно запустить с флагом `--cli`.
